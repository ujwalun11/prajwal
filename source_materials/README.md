# Original uploaded TRANA source bundles

The team supplied two ZIP archives to generate this implementation:
- `trana_prompts_final.zip` — common brief, Person A/B/C role prompts, phase generator prompts and README.
- `contracts_v1_draft.zip` — `events.schema.json`, `openapi.yaml`, `DECISIONS.md`, sample events and sample responses.

The ZIPs themselves were not embedded into this Git repository by the chat integration. Keep the original copies with the team and, before claiming strict contract conformance, extract the second ZIP's contents into `/contracts` without modifying the files. The copied decision table is tracked in `contracts/DECISIONS.md`.
